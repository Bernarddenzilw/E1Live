# Ether Project

Welcome to the Ether project! This repository hosts the source code for an open-source React Native application that aims to provide a seamless experience for live entertainment interaction.

## Purpose
The Ether app is built for entertainment enthusiasts who wish to explore, interact, and enjoy live broadcasting from their favorite entertainers or influencers. It is highly customizable and scalable, making it a suitable foundation for various live-streaming use cases.

## Key Features
- **Live Streaming:** Provides smooth and reliable live streaming capabilities.
- **Engagement Tools:** Integration with chat, polls, and audience interaction features.
- **Cross-Platform:** Mobile compatibility through React Native.
- **Customizable:** Easily extendable and modifiable to fit different streaming needs.

## Setup Instructions

1. Clone this repository:
   ```bash
   git clone https://github.com/Bernarddenzilw/E1Live.git
   ```

2. Navigate to the project directory:
   ```bash
   cd E1Live
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Run the development server:
   ```bash
   npm start
   ```

5. To run on a specific platform:
   - For iOS: `npm run ios`
   - For Android: `npm run android`
